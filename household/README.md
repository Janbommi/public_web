# 우리 집 현황판 · 공개 미리보기

접속: https://janbommi.github.io/public_web/household/

이 폴더가 공개 현황판 프론트엔드의 작업 위치다. 기존 오피스(`/`)와 크립토(`/crypto/`) 페이지는 별도로 유지한다.

## 동작

- 빌드 없이 GitHub Pages에서 실행되는 HTML·CSS·ES module.
- 순자산 / 월 예산 편집 / 가상 카드 승인·중복·취소 / 예비비 마감.
- **모든 기본 금액은 합성한 예시. 실제 계좌·엑셀·카드 알림 자료가 아니다.**
- 공개 카드명도 예시용으로 일반화했다. 개인의 실제 보유 상품 목록을 게시하지 않는다.
- 변경은 이 브라우저의 `ssabu.household.public-demo.v1` 저장소에만 저장한다. 다른 기기·부부 간에 동기화되지 않는다.
- 테스트용 버튼은 실제 결제나 은행 이체를 하지 않는다.
- 공개 페이지에 금융자료를 입력하지 않는다. 로그인·실제 PUSH·비공개 데이터 API는 아직 연결 전이다.

## 파일

`index.html`, `style.css`, `app.js`: 화면. 모든 경로는 이 하위 폴더 기준 상대경로.

`demo-api.mjs`: 브라우저 예시 데이터 어댑터. 네트워크로 금융 정보를 보내거나 받아오지 않는다. 다중 탭 변경은 Web Locks로 직렬화한다. 저장이 실패하면 성공 표시를 하지 않는다.

`lib/domain.mjs`, `lib/seed.mjs`: 계산 규칙과 합성 초기 자료. 로컬 가계 프로젝트의 첫 버전에서 이관했다.

실제 서비스 연결 시에는 별도의 인증된 HTTPS API 어댑터를 추가하고, 해당 서비스에서 부부 권한과 데이터 저장·수집을 처리한다. 로그인 화면만 붙여 공개 JS/JSON 속 실제 잔액을 숨기는 방식은 사용하지 않는다. GitHub 정적 호스팅은 Node.js/SQLite 서버를 실행하지 않는다.

현재 사설 서버 프로토타입 및 상세 Wiki: 로컬 `auto_asset_managing` 프로젝트. 원본 엑셀, 실행 DB, 토큰, 사적인 Wiki는 이 공개 저장소로 이관하지 않는다.
