# 째미즈 asset · 공개 웹

- [카드 합계](https://janbommi.github.io/public_web/household/connect/): 로그인한 가계 구성원에게 수집된 하나Pay 국내 일시불 합계만 표시한다. 일부 수집·미분류이며 전체 이용액이나 확정 지출이 아니다.
- [공유 자산](https://janbommi.github.io/public_web/household/account/): 허용된 구성원이 마지막 확인 잔액을 공유한다. 초기 자산 이관은 별도 진행이다.
- [예산 미리보기](https://janbommi.github.io/public_web/household/): 가상 데이터만 사용하고 변경은 현재 브라우저에 저장한다. 실제 금융자료를 입력하지 않는다.

0.6은 합계·수집 상태를 먼저 배치하고 연결 설정·진단·안내를 접었다. Android 앱은 같은 서명으로 업데이트하며 열린 화면의 로컬 건수를 자동 갱신한다. 실제 단말기에서 새 UI 확인은 별도다.

공개 HTML·CSS·JS·서명된 APK·공개 소스만 게시한다. 인증된 금융자료는 Supabase에 보관하며 정적 파일·소스·로그에 넣지 않는다. 원본 엑셀·실행 DB·연결 키·서명 개인키·비공개 Wiki는 이 저장소에 복사하지 않는다.

이 폴더가 웹 UI의 원천이다. 수정 파일은 기존 자동 커밋·푸시 봇으로 배포된다. 로컬 백엔드·Wiki는 auto_asset_managing 프로젝트에서 관리한다.
