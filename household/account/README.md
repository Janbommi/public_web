# 우리 집 로그인·공유 자산

Supabase Auth 이메일·비밀번호로 로그인한 뒤 관리자가 허용한 가계 구성원만 자산을 조회·수정한다. 프로젝트의 공개용 publishable key만 포함한다. 비밀 키·실제 잔액·계정 명단은 없다.

- 초기 계정은 관리자가 Supabase Auth Users에서 생성하고 확인된 UID를 가계 구성원으로 등록한다. 로그인만으로 접근권을 얻지 않는다.
- 현재는 초기 연결 검증 단계다. 실제 금융자료 이관·대조 전에는 합성 자료로만 검증한다.
- 세션은 메모리에만 보관한다. 새로고침·탭 종료 후 다시 로그인한다. 금융 자료를 localStorage·sessionStorage에 저장하지 않는다.
- 저장은 자산별 버전을 검사한다. 충돌 시 최신 값을 다시 불러오며 자동 덮어쓰기는 하지 않는다.
- 잔액 미입력과 0, 기준일과 조회 시각을 구분한다. 증권 출금가능액은 총평가액에 다시 더하지 않는다.
- 다른 기기 변경은 ‘공유 잔액 다시 불러오기’로 확인한다. 실시간 자동 갱신은 아직 없다.
- 예산·카드 PUSH·예비비는 이 화면에 연결되지 않았다. 상위 페이지는 별도의 가상 미리보기다.

`supabase.mjs`는 @supabase/supabase-js 2.118.0의 고정 버전 브라우저 번들이다. 라이선스는 THIRD_PARTY_NOTICES.txt에 포함한다.
