Android 앱과 진단

키 생성·복사 없이 기기 연결을 준비하고 초대 링크로 새 기기를 승인합니다. 서버에는 월 합계와 중복 방지 정보만 새로 저장합니다. 기존 키·대기 자료를 유지하므로 앱을 삭제하지 않고 업데이트하세요. 처음 감지한 카드는 본인 카드인지 한 번 확인합니다.

Android 앱 1.0 다운로드

이전 설치 보안 경고의 해소 여부는 확인되지 않았습니다. 다시 차단되면 보호 기능을 끄거나 우회하지 말고 중단하세요.

앱 소스 · 서명·권한 확인 · 릴리스

Android 1.0: 각 카드의 ‘해외 결제·취소 보완’에서 카드사로 확인한 원화 금액을 해당 월 합계에 반영할 수 있습니다. 이미 포함된 결제나 이미 차감한 취소는 다시 입력하지 마세요. 취소·해외 PUSH 자동 반영은 실제 카드사 알림 검증 전입니다.

인터넷·절전 상태에 따라 반영이 늦어질 수 있습니다. 애매한 반복 알림은 확인 대기로 보류합니다. ‘전송 대기’라면 앱을 삭제하지 말고 잠시 뒤 상태를 확인하세요.

집계에 필요한 금액·시각은 처리 후 보관하지 않고, 월 합계와 불투명 중복 방지 정보만 새로 저장합니다. 원문·가맹점·카드번호는 보내지 않으며, 폰의 대기 자료는 암호화합니다. 알림 접근은 넓은 OS 권한이지만 연결한 카드 앱만 처리합니다. 보호 기능을 끄지 마세요.

0.94 이하 수동 연결

0.95 이상에서는 앱의 기기 연결에서 설정하세요. 아래 수동 키 기능은 이전 버전용입니다. 기존 키는 다시 만들지 마세요.

  1. 앱 홈의 ‘하나 MOVING ONLINE’ → ‘연결 설정’에서 알림 접근을 허용하고 웹에서 만든 연결 키를 저장합니다.
  2. 다음 평소 하나Pay 일시불 알림을 기다립니다. 대기 중에는 추가 결제나 재설치가 필요 없습니다.
  3. ‘본인 카드 확인하고 자동 집계 시작’에서 카드·금액·시각을 확인하고 ‘맞아요 · 시작’을 누릅니다.

앱의 ‘연결 키 저장’에 붙여넣고 클립보드에서 삭제하세요. 화면을 떠나면 키가 사라집니다. 키·비밀번호는 채팅에 보내지 마세요.
